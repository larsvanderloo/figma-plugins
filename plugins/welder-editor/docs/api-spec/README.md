# API spec briefs

Owned by `figma-api-engineer`. One file per top-level feature or major flow: `<feature>.md`.

Format per `.claude/agents/figma-api-engineer.md`. The brief drives `figma-api-engineer`'s message-bus design and `figma-api-engineer`'s implementation.

Required sections in each brief:

- Purpose statement
- Top-level user flow (per editor type if it differs)
- API inventory (read / mutate / ui bridge / network / storage)
- Per-editor-type notes
- Risk flags
- Reuse opportunities
- Submission gates
- Measurement gaps
