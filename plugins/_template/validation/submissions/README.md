# Figma Community submission packages

Owned by `release-engineer`. One subdirectory per submission, named `YYYY-MM-DD-v<x.y.z>/`.

Required content per submission per `.claude/agents/release-engineer.md` §"Figma Community submission gates":

- Validation reports (e2e gauntlet, vue-tsc, vitest, axe)
- Performance reports (bundle size, large-doc latency)
- Usability test reports if applicable
- Listing copy (title, description, screenshots, video, "what's new")
- Accessibility statement
- Privacy & data disclosure
- Pricing / entitlement test results if applicable
- Open P0/P1 status snapshot
